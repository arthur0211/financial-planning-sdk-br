# Prompt curto do lead v1

> Construa a primeira v1 profissional e local do Financial Planning SDK Brasil. A barra é vencer o V1 Reference Acceptance Pack em correção, paridade SDK/CLI, determinismo, diagnósticos, mutações, instalação, documentação e segurança offline, sem inventar autoridade. Divida o objetivo nas menores fatias julgáveis; para cada fatia, use um builder e um crítico fresco que inspecione a saída real, faça A/B cego quando couber, devolva o maior gap e repita até vencermos ou o owner parar. Mantenha `docs/progress.md` vivo. Use subagents e ultracode; escolha a abordagem.

Este prompt é deliberadamente curto. O contrato observável está em [V1 Reference Acceptance Bar](v1-quality-bar.md); ele define o que “vencer” significa sem prescrever a arquitetura.
